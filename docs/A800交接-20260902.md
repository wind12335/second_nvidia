## 4. ★纪律（4090 会话与用户约定，必须延续）

1. **写完即入库**：新文档/脚本/发现（含负结果）完成即 commit+push，不留"只在机器上"状态。
2. **日期标注**：文件名 `-YYYYMMDD` 后缀；新的一天用新日期；文档首行标日期。
3. **工作目录**：结论报告落 `seconde-paper/work-<今日日期>/`，仓库镜像可版本化内容。
4. **里程碑提交**：每个实验阶段至少一个 commit，message 带关键数字。
5. **大文件不入 git**：逐迭代 CSV/trace/日志走时间戳 tar.gz + SHA256；git 只进清单与分析表。
6. **★交流窗（最重要）**：每完成一批任务，除日志/文档外，**必须**往
   `NVIDIA与海光的交流窗/NVIDIA的进展.md` 写一条：秒级时间戳 + 更新内容 + 想问海光的问题；最新条目在最上；
   海光的回复读他们仓库的 `海光的进展.md`（clone：`https://github.com/wind12335/second_hygon.git`）。
   【急】前缀 = 需要他们尽快答复。
7. **实验红线**（HANDOFF §4）：重叠收益只与同 q、同 GEMM partition 的 B1 串行基线比较；
   不复制/重绘论文原图；不宣称邻居已占阵地；设备标签以实测快照为准；无排序反转就按 No-Go 收缩。
8. **数据纪律**：时间戳结果目录绝不覆盖；失败 case 原样保留；一次重复一行，不只存均值。
9. **跨 run 漂移注意**：4090 容器无法锁频（3–10% 漂移），主结论一律同 run 内比较；A800 若裸机可锁频，
   锁频后跨 run 比较才放开；与海光跨基座只比模式与方向，不比绝对幅度（已与海光约定）。
10. **对海光代码**：只许动 API 兼容性（4 处补丁见 `phaseb-nvidia-port/CHANGES.md`，v3 到机后照流程重放），
