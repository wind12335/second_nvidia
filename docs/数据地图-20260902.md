## 2. 阶段 1 矩阵原始数据（论文主表数据源）

| 内容 | 路径（相对上述根目录） |
|---|---|

| 排序反转审计（q 级 + 候选级） | `stage1_ranking.md` |

矩阵构成：Stage A = 8 shape × q{1,2,4,8,16} × DEFAULT × w0 × 5 rep；Stage B = {S1,S4,S7} × q{4,8,16} × {DEFAULT,RS_ch1,RS_ch4,RS_ch8} × 3 rep；Stage C = {S1,S4,S5} × q{4,8,16} × window{1,2,4} × 3 rep。每 run = 20 warmup + 50 timed，三策略同进程顺序执行。

**逐迭代字段字典**（raw_global_samples.csv）：`t_release_first_us / t_release_last_us / t_done_us / gemm_first_start_us / gemm_last_end_us / e2e_us / correctness / max_abs_error / max_rel_error / window`。R_i = t_release_first（q=1 时即唯一分片）；机制分析 M1–M7 用的就是这些逐迭代样本（每配置 250 个）。
