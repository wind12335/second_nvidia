## 一、研究命题与演化（必须先懂这个）

**原始 H1**：孤立 collective 带宽（busbw）和整体完成时间（T_done）不足以预测端到端最优重叠策略；起决定作用的是分片"可被合法消费时刻"（R_i = t_release − t_issue）、通信-计算资源争用与平台能力边界。

**现状：H1 已三轴全反实锤**（A800 数据）：
1. 库族轴：孤立通信 fcollect(NVSHMEM) 比 NCCL 快 16–22%，但端到端赢家随 N 分化（库族反转 4/11 格）
2. 配置轴：NCCL 强制 Ring/Simple/ch8 孤立差 −20.1%，端到端只差 ±2%（彻底解耦）
3. 结构轴：全串行 B0 在 6/8 shape 称王（连"要不要重叠"都不该默认答要）

**元结论（最重要的可迁移发现）**：预注册判定的 14 条中，方向/形式类 8/9 命中、幅度/阈值类 0/5 全命中——**定律形式可跨基座迁移，参数必须每基座标定**。

**六条总结论**（详细版见 second_nvidia/docs/P8-P17完整判定与总结论_20260903.md）：
1. H1 三轴全反（动机基石）
2. **重叠的必要性是基座变量**：4090(PCIe ~17GB/s) 重叠 8/8 全胜 → A800(NVLink ~145GB/s) 串行广泛称王 → 海光 K500SM_AI(~13GB/s) 介于其间存在 N 边界。三基座谱系=论文跨基座节主图
3. 边界定律形式跨基座成立（P = 截距 + a·q + (b+c·q)·cols），系数平移；A800 版由海光拟合：P=3.29+1.13q+(0.00042−0.00084q)cols，**截距 −44.3→+3.3 变号**（K500→A800）="重叠生存空间被 NVLink 压缩到零附近"的参数化表达
4. 元结论（见上）→ 直接决定系统架构
5. 窗口深度是阈值变量不是旋钮：浅窗（不足一轮在途）有害 30–40%，≥一轮后平直；A800 恢复点 ≤ 半轮；两族协议（NCCL 事件前瞻 w vs NVSHMEM credit 门控 window_mult）并排不合并横轴
6. 四条 PGAS 契约差异 + 平台事实：①put 地址契约相反（NVSHMEM 收本地对称地址/DUSHMEM 收已翻译地址）②release 语义生产侧/消费侧之别（换算桥 18–23µs）③quiet 语义相反 ④同代码跨驱动行为分裂（未 record 事件 4090 宽容/A800 报错）+ 容器锁频被驱动拒绝

**selector v0.3 特征充分性梯度**（论文方法节的架构依据）：
| 方法 | A800 | K500(海光跑的) |
|---|---|---|
| 两项式预测(孤立comm/gemm) | 2/9, p95 15.5%（原理性不可用） | 7/9, 12.01%（部分可用） |
| 最优零知识默认 | d0 (5/9) | **r1 (9/9, regret 0%)** |
| serial-by-bandwidth | 5/9, 3.45% | 0/9, 33.65% |
| probe-1iter | p95 0.08% | 12.51%（重尾） |
| probe-k3 | p95 0.057% | **0.00%** |
→ 结论：孤立特征对重叠路径原理性不可用（gating 开销∝每片计算量，孤立时序中无此信息）；串行族内孤立特征足够；**正确架构=分层选择**（capability 过滤→串行族孤选拿基准→重叠族 ratio 触发时 k≥3 探针挑战）；探针预算 k≥3 双基座共识；两项式在慢基座保留作预排序。海光侧 4090 R_0 数据有 4.09× 重尾、A800 首迭代干净——重尾也是基座相关。
