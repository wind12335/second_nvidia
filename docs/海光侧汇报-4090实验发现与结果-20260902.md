4090 侧跑的是 **NCCL 事件管道线**（runpkg 的 ag-gemm-bench，B0/B1/B2 ≙ 你们的 r0/rs/r1），

## 1. 4090 侧核心发现（通俗版 + 证据）

**发现 A：q 排序反转在 NCCL 侧存在，且找到了两项解析结构。**
8 个 shape 中 5 个出现"通信完成最快的 q ≠ 端到端最快的 q"（按 T_done 该选 q1/q2，端到端最优在 q4/q8）。
进一步把端到端拆开：**T_e2e(q) = R_0(q)[随 q 降] + Tail(q)[随 q 升]**，最优 q 在两线交叉处
（8/8 shape 成立）。带宽指标 T_done(q) 不是这两项中的任何一项——这是"孤立带宽视角失效"的第一性解释，
也可以视作你们"ratio 窗口 0.9–1.35"的机制版：ratio≈1 正是 R_0 与 Tail 相当的交叉区。
（严格 2σ 判据下 1 个 shape 过线；本机容器无法锁频，跨 run 均值漂移 3–10%，其余 4 个方向性成立。
同 run 内比较不受此影响。）

**发现 B：R_0（首分片 release 延迟）是端到端的承载变量，且带重尾。**
全部 40 个 (shape,q) 配置 corr(e2e, R_0)=0.85–1.00。约 6% 的迭代出现 R_0 头部停顿
（正常 2.6ms，停顿时 8ms–943ms；GEMM 段时长纹丝不动，done−R_last≈2µs 恒定）。
后果：S7@q8 上重叠策略按均值"输 25%"、按中位数"赢 18%"——**均值带宽口径会得出颠倒的结论**。
这给你们 P10（wait placement 病理）提供了 NCCL 族的旁证：停顿发生在通信头部，
与 wait/enqueue placement 直接相关（nsys 取证进行中）。

**发现 C：停顿被"全量预入队"的重叠结构放大。**
同配置下 B2（全部分片通信预入队+事件重叠）的 R_0 停顿 15/250 次，B1（串行发射）0 次；
B0 也有 3–9 次 done 停顿。高发配置 = 大输出（每迭代 2×268MB 校验 D2H）+ 大通信。
与你们发现二（d1≡ds、入队顺序是性能变量）同主题、反向呈现：
你们那边名义重叠塌缩成串行；我们这边重叠中位数真有效、但预入队结构引入头部停顿风险。
合起来说明"协议里写的依赖 ≠ 运行时执行的依赖"在**两个基座上都成立**，只是崩法不同。

**发现 D：重叠收益本身扎实（红线合规口径）。**
同 q、同 GEMM partition 的 B2/B1 逐 run 比较：8/8 shape 正收益，
平衡型最强（S4@q16 = 1.482±0.046，5 run 范围 1.429–1.518），
通信主导封顶在 ~1.12（GEMM 太小，重叠天花板低），计算主导非单调（S7 q4 1.15 → q8 均值 0.80/中位 1.18）。

## 3. 平台事实（你们 env_check 要的重点，先给结论版）

- RTX 4090 / sm_89 / 4 GPUs / PCIe；driver 580.65.06；nvcc 12.6.85；OpenMPI 4.1.2。
- **拓扑与你们预期不同处**：4 卡分属 4 个 NUMA（2/0/7/6），全对 SYS，无 PIX/PXB/NVLink；NIC0=mlx5_bond_0 未用。
- NCCL 系统库 **2.28.3**（ldd + 运行日志双核对；非 2.30.x、非 v3.6.5-dev → 经典 2.x 逐 collective kernel 语义）。
- transport 实测（2 卡 preflight）：SHM/direct/direct，2 coll + 2 p2p channels/peer，P2P chunk 131072。**无 P2P**（消费级平台），与你们 README 风险 4.5 预判一致 → NVSHMEM put/signal 预计走 host proxy，跨基座数值不可直接比，只比模式。
- NVSHMEM = pip wheel **3.6.5**（`nvidia-nvshmem-cu12==3.6.5`；源码快照未随迁移到本分区）。
  **`nvshmemx_fcollectmem_on_stream` 在 3.6.5 存在**（你们头号编译风险在本版本不成立）。
- 容器内**无法锁频**（nvidia-smi -lgc 被拒）——所有跨 run 均值带 3–10% 漂移，已按"同 run 内比较"纪律处理。
- p2p_probe 实测（canAccessPeer 矩阵 + D2D 带宽矩阵）：[待 GPU 空闲补跑，env_check_report.txt 届时回传]
